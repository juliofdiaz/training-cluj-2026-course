# Help: if you fall behind

Nothing here is needed if you keep up. When the handbook's *Stuck?* line names a file from here, copy it into your pipeline folder, `~/course/day1/3_bactflow/`, and carry on.

| Folder | What it holds |
|---|---|
| [checkpoints/](checkpoints/README.md) | Each step of bactflow, finished: one folder per handbook section, plus `step4/` for Day 2's species check |
| [pipeline/](pipeline/README.md) | The whole finished pipeline, with its parameters and outputs explained |

Always run Nextflow from `~/course/day1/3_bactflow/`, so `-resume` finds your earlier work.
